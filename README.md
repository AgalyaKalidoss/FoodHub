# FoodHub – Food Ordering Website

FoodHub is a responsive and user-friendly food ordering website developed using **HTML, CSS, and JavaScript**. The project provides a clean interface for exploring food items and interacting with different sections of the website.

## 🌐 Live Demo

**[View FoodHub Live](https://agalyakalidoss.github.io/FoodHub/)**

## 💻 GitHub Repository

**[View Source Code](https://github.com/AgalyaKalidoss/FoodHub)**

---

## 📌 About the Project

FoodHub is a frontend web development project created to demonstrate the use of **HTML, CSS, and JavaScript** in building a responsive and interactive food-related website.

The website focuses on a simple user experience with an attractive layout, organized food sections, and JavaScript-based interactions.

---

## ✨ Features

* 🍔 Attractive food ordering interface
* 🍕 Food item browsing
* 🛒 Interactive user interface
* 📱 Responsive design
* 🎨 Clean and modern layout
* ⚡ JavaScript-based interactions
* 🖥️ Works across different screen sizes

### 1. Clone the Repository


### 2. Navigate to the Project

```bash
cd FoodHub
```

### 3. Run the Project

Open the `index.html` file in any modern web browser.

No additional packages or dependencies are required.
